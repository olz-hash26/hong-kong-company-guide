# Hong Kong Company Guide

Responsive static GitHub Pages resource hub about Hong Kong company research.

## Publish
1. Commit the website files to the repository root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, branch `main`, folder `/ (root)`.
4. Save and wait for the Pages deployment.

The site is configured for `https://olz-hash26.github.io/hong-kong-company-guide/`.

Includes a homepage, five original educational guides, responsive CSS, canonical metadata, internal links, `sitemap.xml` and `robots.txt`. It is an independent resource, not an official government website. Verify legal and filing information against current official sources.
